# Cite and link sources

Everything the connector returns comes from a page in the Eric's New York guide. The user should be able to open that page.

## The rule

Every answer that uses connector data names the source and links it.

- Name: use the name in the result's `attribution` line.
- Link: use the link returned with the result.

## Which link

- Prefer the link of the specific page (the show, the itinerary, the article) over the site's home page.
- Use the link exactly as returned, including anything after a question mark. Do not shorten, rebuild or guess a link.
- One link per item is enough. In a list of five shows, each show carries its own link.

## Partner pages

Some results, events in particular, link to a partner's ticket page instead of the guide. Say that it is a partner's ticket page.

## When there is no link

If a result came back without a link, say that the information comes from Eric's New York and give no link. Never invent one.

## Mixing sources

If you add something from your own knowledge, keep it apart from what the connector returned, so the user can tell which statements the guide stands behind.
